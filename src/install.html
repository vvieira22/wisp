Instalar o Wisp no celular

Siga os passos abaixo para usar o Wisp como app de tela cheia.

HTTPS está desligado no PC.

Não dá para instalar como app assim. Você ainda pode usar o Wisp pelo navegador.

Usar o Wisp na web

1. Certificado

Baixar certificado

Baixe, abra o arquivo baixado e instale como certificado CA.

      2. Abrir o Wisp

      Aguardando o certificado…
      Abrir Wisp

      Com o Wisp aberto, use o menu do navegador → Instalar app (ou Adicionar à tela inicial → Instalar app).

      Se ele pedir pareamento, volte ao PC e escaneie o QR de novo.
